# ORBIT

安装：`npm install`

本地启动：`npm run dev`

检查：`npm run typecheck`，`npm run build`。

Docker 启动：`docker compose up --build`，打开 http://localhost:8517 。

## 取景交互

- **单指 / 鼠标拖动**：真正“抓住”景物——按下时把指针位置反投影为球面世界方向并记为锚点，之后每次移动都用当前指针位置在球面上闭式求解 `(yaw, pitch)`，使锚点始终位于指针正下方。不做屏幕角度的增量累计，因此起点靠近极点、跨经线、画布被响应式布局缩放时都不会漂移。
- **双指**：同时旋转（roll）与缩放（zoom），以双指落下瞬间的取景与指距、指向角为基准，质心在球面上锚定。手指数量增减时以当前实际取景重新取基准，视角不跳变。
- **惯性**：松开最后一只指针时按最近约 100ms 的速度进入指数衰减滑行；滑块、快捷缩放、滚轮、重置、导出或新手势等任何显式输入都会立即打断惯性，最新输入优先。
- **奇异区域的明确行为**：投影轴附近（屏幕中心，偏航不可稳定求解）与投影赤道奇异点（俯仰不可稳定求解）内，冻结对应自由度、另一自由度仍精确求解；离开区域时用当前实际取景重新锚定，不产生跳变。锚点在几何上不可达（roll 固定时 `|anchor.y|` 超出可达域，或俯仰触及 ±85° 限制）时，视图取最近可达取向，锚点暂时滑动、回到可达域后自动恢复精确跟随。
- **中断**：`pointercancel`、指针捕获被收回、窗口失焦、页面隐藏都会结束当前手势（系统中断不补惯性）。
- **导出**：触发导出时先终止惯性等未结束的异步运动，快照即触发瞬间的实际取景。
